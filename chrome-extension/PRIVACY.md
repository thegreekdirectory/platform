# Privacy

The extension runs only on Google Maps pages. It does not request a user's name, email, Google account, search terms, browsing history, or location.

A random installation identifier is stored locally to apply request limits. Directory checks send Google Place IDs only. Lookup results are held in Chrome session storage for up to three hours and clear when the browser session ends. If a user submits a suggestion, the extension sends the business name, Place ID, available address, relationship selection, and optional note for manual review.

No analytics or advertising code is included. Local installation and submitted-ID data are removed when the extension is uninstalled or its data is cleared.
